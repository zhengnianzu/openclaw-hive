# MEMORY.md - 长期记忆

你的经验积累。USER.md 记录「用户是谁」，这里记录「我和用户之间发生过什么、我学到了什么」。

## 该记什么

- **经验教训**: 某次操作踩了坑，下次怎么避免
- **用户偏好**: 用户表达过的喜恶（「别推荐 X」「喜欢 Y 风格」）
- **项目进展**: 当前在做什么、到了哪个阶段、关键决策及原因
- **工作模式**: 反复出现的习惯（「代码风格偏好 explicit > implicit」）
- **待办与承诺**: 答应用户要做但还没完成的事

## 不该记什么

- 单次会话的琐碎细节 → 放 `memory/YYYY-MM-DD.md`
- 用户的固定信息（称呼、时区）→ 放 `USER.md`
- 过时的信息 → 定期清理

## 维护原则

- 定期审视，删除已过时的条目
- 日志是原始素材，这里是精炼后的精华
- 这个文件应该越来越有用，而不是越来越长

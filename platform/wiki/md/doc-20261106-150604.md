一、目的：

每次批跑rollout轨迹，配置一组skills。那么最后所有跑出的轨迹就能够见到不同搜索工具的名称和调用方式了，不会因为只有一种，而出现模仿学习的偏置，以实现训练的数据增强。

任务需使用以下镜像。

swr.cn-east-4.myhuaweicloud.com/rl_team/multiharness:no-serper-26.11.9

二、使用流程：

1\. 搜索泛化skills库，依托serper api构建。其中有30组技能，由4种基础技能泛化而来：

&#x20; （1）serper-v2：搜索并返回5条结果包含页面内容；

&#x20; （2）serper_snippets：搜索并返回5条（or 10条，or20条）摘要，不包含页面内容；

&#x20; （3）retrieve：使用一个url，例如serper_snippets返回的，来读取该页面的内容；

&#x20; （4）serper_snippets_retrieve:serper_snippets和retrieve的组合。

&#x20;  详见附件中各个skill的SKILL.md文件。其他技能由这4种基础技能改变名称调用方式和描述等演变而来。

每次批跑任务，随机选择一组使用，例如，选择groups5（可参照本页面最底下的技能分组），则会使用："retrieve", "serper-v2"和"serper_snippets" skill。

2\. 搜图泛化skills库。包含了15个image-search skill，每次批跑随机选择一种，例如"image-search-ultra"。

3\. 那么就构建了一组技能：

retrieve,

serper-v2,

serper_snippets,

image-search-ultra

\# 批量给 task config 注入 skill

\`inject_skills.py\` 支持传入目录，为其中每个 config JSON 独立随机选择一组 serper-search 技能和一个 image-search 技能，就地追加到 \`agents\[].skills\`。也兼容传入单个文件。

\## 用法

\`\`\`powershell

python .\inject_skills.py "C:\Users\w00986934\Desktop\task批跑\task_configs"

python .\inject_skills.py "C:\Users\w00986934\Desktop\task批跑\task_configs" --dry-run

python .\inject_skills.py "C:\Users\w00986934\Desktop\task批跑\task_configs" --seed 42

python .\inject_skills.py "C:\Users\w00986934\Desktop\task批跑\task_configs" --agents main

python .\inject_skills.py "C:\path\config.json"

\`\`\`

以上命令在本脚本所在目录执行；其他位置执行时使用脚本完整路径。

\## 行为约定

\- 只处理指定目录直接包含的 \`.json\` 文件（扩展名大小写不限），不递归子目录。目录应只放需要修改的 config。

\- 按文件名排序，每个文件独立抽取一次：从 \`serper_groups\` 里随机选一整组，组内技能全部写入；从 \`image_search_skills\` 里随机选一个。

\- 随机结果允许重复，不保证不同文件必定选中不同组合。

\- 同一文件中，默认所有 agent（包括 \`main\` 和 \`evaluator\`）拿同一组、同一个 image 技能。\`--agents main\` 可以仅处理 main。

\- 已有技能全部保留，只追加尚不存在的新名字。多次运行可能叠加不同组，不会清除之前的技能。

\- \`--seed\` 固定整个批次的随机种子；相同文件集合、内容和技能库下可复现选择。\`--dry-run\` 不写入文件。

\- 每个文件单独通过临时文件加 \`os.replace\` 原子写回。整个批次不是事务：一个文件失败不会回滚已写入的文件，而是报告错误并继续。

\- 最后打印成功和失败数量；有失败时退出码为 1，无失败为 0。路径不存在或空目录会报错。

\- 技能库默认使用脚本同目录的 \`skills_library.json\`，可通过 \`--library\` 指定其他库。

5\. 修改 TOOLS.md:

可使用附件中提供的TOOLS.md

具体改动如下

原：

\## Serper

**优先用serper进行搜索**：如果需要进行互联网搜索，请你\*\*优先使用serper进行网络搜索（如google）\*\*，此工具稳定且专业，是最优的搜索选择。如果serper不能正常运行，再考虑使用其他功能呢。

**其他搜索方式**：只有serper尝试过并且执行失败时，才考虑使用web_fetch/browser工具。

修改为：

\## 网络搜索工具

**优先使用搜索skill工具进行搜索**：如果需要进行互联网搜索，请你\*\*优先使用我们提供的搜索skill工具进行网络搜索\*\*，这些工具稳定且专业。如果这些搜索skill工具不能正常运行，再考虑使用其他工具。

web_search这个工具可能无法正常工作，如果它无法正常工作，则禁止使用它。
